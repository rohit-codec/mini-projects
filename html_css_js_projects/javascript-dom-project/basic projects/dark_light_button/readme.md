# Dark / Light Mode

A simple mini project built using **HTML, CSS, and JavaScript** that allows the user to switch between dark mode and light mode.

## 🚀 Features

- Toggle between dark and light mode
- Changes page background and text colors
- Changes container styling
- Button text changes automatically
- Smooth transition effect
- No page refresh
