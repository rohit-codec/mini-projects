# Counter App

A simple counter mini project built using **HTML, CSS, and JavaScript**.

The counter can be increased, decreased, or reset using the buttons.

## 🚀 Features

* Increase counter
* Decrease counter
* Reset counter to 0
* Simple and responsive UI
* No page refresh

## 📁 Project Structure

```text
counter-project/
│
├── index.html

├── script.js
└── README.md
```

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* Event Handling

## ⚙️ How It Works

A JavaScript variable stores the current counter value:

```javascript
let value = 0;
```

The buttons modify this value:

```javascript
value++;
```

```javascript
value--;
```

For reset:

```javascript
value = 0;
```

The updated value is displayed using:

```javascript
count.textContent = value;
```

## 🎯 Concepts Practiced

* `let`

## ▶️ How to Run

Open `index.html` in a browser and use the **Increase**, **Decrease**, and **Reset** buttons.
