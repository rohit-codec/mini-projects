# Event Delegation Task Manager

A simple **Task Manager mini project** built using **HTML, CSS, and JavaScript** to understand and practice **Event Delegation**.

Users can add tasks, mark tasks as completed, and delete tasks. The main purpose of this project is to demonstrate how a **single event listener attached to a parent element can handle events from multiple child elements**, including dynamically created elements.

---

* Dynamic task creation

## 🎯 Main Concept: Event Delegation

The main purpose of this project is to understand **Event Delegation**.

Instead of adding separate event listeners to every button:

```javascript
completeButton.addEventListener("click", ...);

deleteButton.addEventListener("click", ...);
```

we attach **one event listener to the parent element**:

```javascript
taskList.addEventListener("click", function(event) {
    // Handle button clicks
});
```

The parent `taskList` handles clicks coming from its child elements.

---

## 🧠 How Event Delegation Works

The task list has multiple task elements:

```text
taskList
│
├── Task 1
│   ├── Complete Button
│   └── Delete Button
│
├── Task 2
│   ├── Complete Button
│   └── Delete Button
│
└── Task 3
    ├── Complete Button
    └── Delete Button
```

Instead of creating event listeners for every button, we use one listener:

```javascript
taskList.addEventListener("click", function(event) {

});
```

When a button is clicked, the event **bubbles upward** from the button to its parent elements.

The `taskList` can therefore detect the click.

---

## 🔄 Event Bubbling

Event Delegation works because of **Event Bubbling**.

For example, if the user clicks the Delete button:

```text
Delete Button
      ↓
Task Actions
      ↓
Task
      ↓
Task List
      ↓
Container
      ↓
Body
      ↓
Document
```

The event travels from the clicked element toward its ancestors.

This allows the parent `taskList` to handle events generated by its children.

---

## 🔍 `event.target`

The `event.target` property tells us which element actually triggered the event.

Example:

```javascript
taskList.addEventListener("click", function(event) {

    console.log(event.target);

});
```

If the user clicks the Delete button, `event.target` refers to that button.

---

## 🔎 Using `closest()`

The project uses:

```javascript
const clickedButton = event.target.closest("button");
```

This finds the nearest button related to the clicked element.

Then:

```javascript
const task = clickedButton.closest(".task");
```

finds the task containing that button.

This allows the program to determine exactly which task should be modified or deleted.

---

## ➕ Adding Tasks Dynamically

When the user submits the form, JavaScript creates a new `<li>`:

```javascript
const task = document.createElement("li");

task.classList.add("task");
```

Then the task content is added:

```javascript
task.innerHTML = `
    <span class="task-text">
        ${taskText}
    </span>

    <div class="task-actions">

        <button class="complete-btn">
            Complete
        </button>

        <button class="delete-btn">
            Delete
        </button>

    </div>
`;
```

Finally:

```javascript
taskList.appendChild(task);
```

adds the new task to the page.

---

## ⭐ Why Event Delegation Is Important Here

The task buttons are created **after the page loads**.

For example:

```text
Page loads
    ↓
No tasks exist
    ↓
User adds Task 1
    ↓
Task 1 buttons are created
```

If we attached listeners only to buttons that existed when the page loaded, newly created buttons would not automatically have those listeners.

Event Delegation solves this problem.

The listener is attached to the parent:

```javascript
taskList.addEventListener("click", ...);
```

Therefore, newly added buttons can also be handled.

---

## ❌ Without Event Delegation

A less efficient approach would be:

```javascript
completeButton.addEventListener("click", ...);
deleteButton.addEventListener("click", ...);
```

for every task.

If there are 100 tasks, many individual event listeners would be created.

---

## ✅ With Event Delegation

Only one listener is required:

```javascript
taskList.addEventListener("click", function(event) {

    // Handle all task button clicks

});
```

It can handle:

```text
Task 1 → Complete
Task 1 → Delete

Task 2 → Complete
Task 2 → Delete

Task 3 → Complete
Task 3 → Delete

...

Task 100 → Complete
Task 100 → Delete
```

## 🧩 JavaScript Concepts Practiced

### Event Listener

```javascript
addEventListener()
```

Used to listen for events.

### Form Submit Event

```javascript
taskForm.addEventListener("submit", ...)
```

Used to handle form submission.

### `preventDefault()`

```javascript
event.preventDefault();
```

Prevents the browser from refreshing the page after form submission.

### Event Delegation

```javascript
taskList.addEventListener("click", ...)
```

Allows one parent listener to handle events from multiple child elements.

### Event Bubbling

Events travel from the target element toward its ancestors.

### `event.target`

Identifies the element that triggered the event.

### `closest()`

Finds the nearest matching ancestor element.

task.classList.toggle("completed");

### `remove()`

```javascript
task.remove();
```

Removes a task from the DOM.

### `createElement()`

```javascript
document.createElement("li");
```

Creates a new HTML element dynamically.
