# Stopwatch

A simple and responsive **Stopwatch** mini project built using **HTML, CSS, and JavaScript**.

The stopwatch allows the user to start, pause, reset the timer, and record lap times.

## Features

- Start the stopwatch
- Pause the stopwatch
- Reset the stopwatch
- Record lap times
- Display time in `HH:MM:SS` format
- Prevents multiple timers from running simultaneously
- Displays all recorded laps
- Responsive design
- No page refresh

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Handling
- `setInterval()`
- `clearInterval()`
