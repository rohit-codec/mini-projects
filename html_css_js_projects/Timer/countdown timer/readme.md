# Countdown Timer

A simple and responsive **Countdown Timer** built using **HTML, CSS, and JavaScript**.

The user can enter **hours, minutes, and seconds** and control the countdown using Start, Pause, and Reset buttons.

## Features

- Enter hours, minutes, and seconds separately
- Start the countdown
- Pause the countdown
- Reset the countdown
- Displays time in `HH:MM:SS` format
- Shows an alert when the timer reaches zero
- Prevents multiple timers from running at the same time
- Responsive design
- No page refresh

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Handling
- `setInterval()`
- `clearInterval()`
