# Digital Clock

A simple and responsive **Digital Clock** built using **HTML, CSS, and JavaScript**.

The clock displays the current time and date and automatically updates every second.

## Features

- Displays current time
- Displays AM/PM
- Displays current date
- Updates every second
- 12-hour time format
- Responsive design
- No page refresh required

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Date Object
- `setInterval()`
