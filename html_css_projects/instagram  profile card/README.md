# Instagram Profile Card

A simple Instagram-inspired profile card built using **HTML and CSS**.

The main purpose of this project is to practice **CSS Flexbox, card styling, gradients, transitions, and responsive design**.

## Technologies Used

- HTML5
- CSS3

## CSS Concepts Practiced

- **`display: flex`** — used to center the card and arrange the profile statistics.
- **`justify-content` and `align-items`** — used to control alignment and spacing.
- **`flex: 1`** — used to give the statistics equal space.
- **`linear-gradient()`** — used for the Instagram-style background.
- **`border-radius`** — used for the card and circular profile image.
- **`box-shadow`** — used to create depth around the card.
- **`transition` and `:hover`** — used for smooth card and button effects.
- **`object-fit: cover`** — keeps the profile image properly fitted inside the circular image area.
- **Media queries** — used to improve the layout on smaller screens.
- **`focus-visible`** — provides a visible keyboard focus state for the button.

## How to Run

1. Download or clone the repository.
2. Open the `instagram-profile-card` folder.
3. Make sure `profile.jpg` is in the same folder as `index.html`.
4. Open `index.html` in a web browser.

No installation or JavaScript is required.
