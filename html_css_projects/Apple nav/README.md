# Apple Website Navbar

A simple **Apple-inspired navigation bar** built using HTML and CSS.

The main purpose of this project is to practice **CSS Flexbox** and understand how it can be used to create a clean and responsive navigation layout.

> **Note:** This project is only a visual navbar. The links and buttons are not functional because it is built only with HTML and CSS.

## Technologies Used

* HTML5
* CSS3
* Font Awesome

## CSS Concepts Practiced

* **`display: flex`** — used to create the main navbar layout.
* **`justify-content`** — used to distribute and center navbar elements.
* **`align-items`** — used to vertically align the logo, menu, and buttons.
* **`gap`** — used to create consistent spacing between menu items and buttons.
* **`flex-direction`** — changed the layout from row to column on smaller screens.
* **`flex-wrap`** — allows menu items to move to the next line on smaller screens.
* **Media queries** — used to make the navbar responsive.
* **Hover effects** — used to change the appearance of links and buttons when hovered.

## How to Run

1. Download or clone the repository.
2. Open the `apple-navbar` folder.
3. Open `index.html` in a web browser.
4. An internet connection is required for the Font Awesome Apple icon to load.
