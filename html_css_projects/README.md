# Profile Card

A simple profile card built using **HTML and CSS**.
The main purpose of this project is to practice **CSS positioning** and basic styling.

## Technologies Used

* HTML5
* CSS3

## CSS Concepts Practiced

* **`position: sticky`** — used for the header so it stays at the top while scrolling.
* **`position: relative`** — used on the profile card to create a reference point for positioned elements.
* **`position: absolute`** — used to position the badge and contact button precisely.
* **`position: static`** — used for the contact button on smaller screens to return it to the normal document flow.
* **`top`, `right`, `bottom`** — used with positioning properties to control element placement.
* **`z-index`** — used to control the stacking order of the sticky header.
* **Media queries** — used to make the card responsive on smaller screens.
* **`transform` and `transition`** — used for hover animations.
* **Box model properties** — `margin`, `padding`, `border`, and `border-radius` used to structure and style the card.
